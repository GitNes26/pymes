# CLAUDE.md

Las instrucciones del proyecto para cualquier agente están en **[AGENTS.md](./AGENTS.md)** — léelo primero.

Recordatorios clave:
- Cualquier cambio a la base de datos → además de la migración en `db.js`, entrega el **script SQL de MySQL 8** para correr en el servidor (y guárdalo en `docs/sql/`).
- Al terminar un cambio visible, agrega una línea a `CHANGELOG.md`.
